## 🚀 Launch Pipeline

ScrollVerse Empires features a **cohesive launch pipeline** that consolidates all artifacts for deployment. The pipeline is anchored by our **DAO-first strategy**, making governance the opening move.

### Quick Start

```bash
# Navigate to deployment directory
cd deployment

# Review the complete artifact manifest
cat ARTIFACTS.md

# Execute the launch pipeline
./scripts/launch-pipeline.sh

# Verify deployment
./scripts/verify-deployment.sh
```

### Pipeline Structure

```
deployment/
├── README.md              # Deployment overview and guide

    ├── governance-strategy.md    # DAO governance approach
```
