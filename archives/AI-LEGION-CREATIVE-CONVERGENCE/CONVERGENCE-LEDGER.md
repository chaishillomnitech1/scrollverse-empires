## Research questions

1. Which recurring creative structures appear across the different branches?
2. Which elements are attributable to the creator's direction, which to model capabilities, and which to inherited cultural patterns?
3. Which outputs are original ScrollVerse IP versus transformative/inspired works?
4. Can the workflow be reproduced by another creator using the same tools and materially similar prompts?
5. Which outputs generate durable audience response?
6. Which artifacts have scripts, source files, timestamps, commits, exports, or deployment records?
7. Which branches become books, games, films, music, merchandise, or Omniland experiences?

## Method

`OBSERVE → RECORD → CLASSIFY → TRACE → REPRODUCE → VERIFY → PRESERVE → EVOLVE`

## Evidence classes

- **R1 — Creator report:** supplied by creator/transmission.
- **R2 — Public artifact:** publicly observable page/channel/video/repository.
- **R3 — Reproducible:** independent reproduction or repeatable workflow evidence.
- **R4 — Operational:** running system or deployment evidence.
- **R5 — On-chain:** independently readable transaction/contract evidence.
- **R6 — Independent:** evidence verified outside the creator/AI workflow.
- **C — Creative interpretation:** useful canon or metaphor, not an empirical claim.

## Governing rule

Maximum reconstruction does not mean maximum claims. Preserve the full signal while keeping every statement attached to its evidence class.
